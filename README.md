# Halloween Wardrobe · 萬聖節換裝室

[開啟互動畫廊](https://nutcelvischen-jpg.github.io/halloween-wardrobe/)

18 套可編輯 SVG 萬聖節裝扮，搭配同一個個人頭像：太空人、恰吉、吸血鬼、木乃伊、巫師、南瓜、海盜、科學怪人、骷髏、機器人、黑貓、恐龍睡衣、蘑菇精靈、復古潛水員、殭屍道長、蜜蜂、南瓜紳士、幽靈甜點師。

支援慢速轉頭與頸部連動、飛行小鬼、驚訝表情、配件切換、暫停動畫、減少動態效果與單張 SVG 下載。

## 使用與編輯

直接開啟 `index.html` 可離線使用，無外部執行依賴。

- `build.py`：服裝繪圖與組裝。
- `extras.py`：新增八套服裝與配件。
- `headgear.py`：頭盔、帽子與妝容。
- `template.html`：畫廊樣式與互動。
- `avatar-source.svg`：共用頭像。
- `svg/`：基礎服裝；`svg/headgear/`：完整配件版本。

修改後執行 `python3 build.py`，再提交產生的檔案。
